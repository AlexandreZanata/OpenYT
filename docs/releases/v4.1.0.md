# OpenYT 4.1.0

This release consolidates Timed Subtitle Search (`NX3`) and Study Mode (`NX4`, closing Milestone 2) across desktop and Android.

- **Timed search within saved media:** SQLite FTS4 + `unicode61` indexing over normalized SRT/VTT tracks, bounded scoped search with accent folding and excerpt highlights, entry-aware timestamp playback (`<= 1000 ms` seek accuracy), and pre-join pagination keeping 100k-cue synthetic search p95 within budget (`67.17 ms` locally).
- **Study mode & A/B repetition:** SQLite schema v24 persistence for timestamped notes, bookmarks, saved ranges, studied completion, and collection progress; atomic snapshot capture and stale-callback/unsaved-draft guards; explicit 5-loop A/B repeat bounds across Linux/Windows VLCJ (`maxOvershootMs <= 402`, `maxReturnDeltaMs = 0`) and Android Media3.
- **Safe Markdown export & local deep links:** non-cascading record removal preserving user files, credential/path-free study exports, and `openyt://library/entry/<id>?t=<ms>` routing with Windows UTF-16LE `reg import` HKCU registration, Linux XDG handler registration, and Android `singleTop` + `CLEAR_TOP` intent handling.
- **Android 13–16 playback/PiP reliability:** removes unsolicited `POST_NOTIFICATIONS` permission modal from `PlayerActivity.onCreate()` so PiP transitions and deep-link timestamp reopens keep window focus cleanly.
- **Validation:** Linux unit/integration/media/VLCJ/`.deb` offline & online suites (`DesktopYtDlpEngineIntegrationTest` 6/6, `validate-linux.sh` offline & `inspect`/`download`/`playlist`), Windows CI MSI/EXE installed contracts, macOS CI desktop suite, and Android Emulator instrumentation suite. Real physical Xiaomi Android 16 (`2311DRK48G`) validation ran 22/24 prior to removing the `PlayerActivity` permission popup and verified both previously failing tests once permission was granted; clean-install device re-run remains gated on manual HyperOS USB install confirmation.
