# OpenYT 4.2.0

This release consolidates the verified personal-library expansion, including
durable offline assets, portable backup and recovery, subscription rules and
multi-clip export. Timed subtitle search and study mode remain available across
desktop and Android.

## New and improved

- **Offline library:** owned artwork/subtitle assets, readiness indicators,
  pinning, configurable cache budgets and explicit cleanup previews.
- **Portable backup:** streamed media/context exports and confirmed restore with
  checksums, safe path validation, new IDs and rebuilt subtitle search indexes.
- **Assisted recovery:** locate moved files, preview exact-content matches,
  preserve collections/study/checkpoints and review duplicates without deleting
  original media.
- **Subscription rules:** duration filters, approved download profiles, backlog
  limits, free-space reservations and supported connection/power conditions.
  Deferred candidates survive restart; preview is read-only and replay requires
  explicit approval.
- **Optional Android background discovery:** bounded WorkManager checks use the
  existing application process. They queue eligible episodes; downloads require
  the app to be open. Android may defer checks, and force-stop is not bypassed.
- **Batch clips:** multiple ranges, precise encoding or keyframe copy, portrait
  fit/crop, existing subtitle captions, selected-time covers, private preview,
  source-bitrate storage estimates, per-clip results, cancellation and retry.
- **Reliability:** atomic clip/library receipts, ownership-aware cover recovery,
  preserved authors/source hashes, correct anamorphic/rotated framing and
  cancelable RSS/metadata inspection without interrupting another download.
- **Clearer feedback:** export preparation status, selected-batch success counts,
  localized rule decisions and responsive controls for narrow/large-text layouts.

## Validation and compatibility

The expansion was exercised with real bundled tools and players on Linux,
Windows 11 in the existing Docker VM (installed MSI and EXE) and Android API26/API36
emulators, including separate real internet downloads. The final expansion CI
passed Linux, Windows, macOS rendering and Android instrumentation:
[CI 43653025917](https://github.com/AlexandreZanata/OpenYT/actions/runs/43653025917).

Release publication additionally requires successful native packaging, installed
Windows/macOS smoke checks, engine contracts and per-platform dependency
inventories. Detailed commands, screenshots, skipped opt-in checks and limits are
in the [validation ledger](https://github.com/AlexandreZanata/OpenYT/blob/main/docs/testing/NEXT_EXPANSION_VALIDATION.md).

SQLite upgrades to schema 26 through the existing migrations. Record removal does
not delete original media. Android versionCode increases to 43; the configured
production signing key remains unchanged.

## Downloads and signatures

Assets include the Android APK, Windows MSI/EXE, macOS DMG, Linux DEB/RPM/AppImage/
Flatpak/Arch packages and the optional browser handoff ZIP. Per-platform
CycloneDX inventories accompany the downloads.

`SHA256SUMS.txt` has a detached RSA signature verifiable with the published
`release-signing-public-key.pem`. Android uses the available production signing
key. **Windows installers have no Authenticode certificate, and the macOS bundle
is not notarized.** Windows SmartScreen/macOS Gatekeeper may therefore warn;
the signed checksum manifest does not replace OS code signing.

## Explicit limits

- Automatic desktop timer/task/LaunchAgent registration and production offline
  speech recognition did not pass their optional shipping gates. Bounded manual
  CLI discovery and subtitle-based search remain available.
- Emulator results do not certify physical-device battery or thermal behavior.
- The loaded local Windows VM showed slow startup and one 90-second timeout;
  the same artifacts passed the full rerun, with separate faster CI measurements.
  See the ledger for the retained evidence.
- A process crash can leave private preview cache files for later cleanup.
