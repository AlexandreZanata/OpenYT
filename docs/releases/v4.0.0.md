# OpenYT 4.0.0

- Follow the operating system language automatically, with Portuguese and English
  overrides in Settings.
- Continue the last playback session, use ±10-second shortcuts, Android PiP and a
  desktop floating mini-player. Embedded desktop playback requires VLC/libvlc.
- Select subtitles, audio conversion presets, volume normalization, chapters,
  opt-in SponsorBlock marking, bounded live recording and segment previews.
- Create clips or converted audio files while preserving the original.
- Subscribe locally to RSS/podcasts and watch playlists while the app is open.
- Search the installed engine's source catalog, with reviewed source logos and
  named fallback tiles for other extractors.
- Open validated `openyt://` links and use the optional browser handoff. Clipboard
  suggestions and download notifications are off by default.
- Correct final-output detection, Unicode/Windows paths, storage recovery, paused
  queue cleanup, retry state and standalone subtitle completion.
- Verify assisted installers against a signed SHA-256 manifest, include a CycloneDX
  inventory, and optionally update yt-dlp after checksum verification.

Android uses the available production signing key. Windows and macOS installers
currently do not have Authenticode/notarization certificates. The signed checksum
manifest authenticates release files and does not replace those OS certificates.
The app always leaves installation confirmation to the operating system/user.

Generic image-gallery downloads and a second extraction engine were rejected for
this release under the documented runtime/engine constraints (ADR-0023). A source
appearing in the catalog does not guarantee access or availability at that site.
