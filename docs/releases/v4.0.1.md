# OpenYT 4.0.1

This release fixes Windows playback, Show in folder and installer shortcuts.

- **Play:** Windows now includes checksum-pinned VLC 3.0.24 runtime libraries and
  plugins. Embedded playback and the floating mini-player no longer require a
  separate VLC installation. Linux/macOS keep their documented VLC requirement.
- **Open and Show in folder:** use native Unicode Windows shell operations;
  Explorer selection is confirmed after its view loads, including the first
  opening of a video-only folder and names with accents and spaces.
  External-player fallback uses the same corrected adapter.
- **Visible failures:** Library and Downloads show localized recovery messages
  when opening/revealing fails. Blocking shell calls run off the UI thread.
- **Installer shortcuts:** both MSI and EXE request branded desktop and Start-menu
  shortcuts.
- **Regression gates:** both real Windows installers are installed and exercised
  in CI, including shortcut launch, an actual associated-file handler, Explorer
  first-open MP4 selection and visible decoded RGB playback using the packaged
  JVM and bundled libVLC. Both formats also passed on a local Windows 11 VM.

currently configured: production Android signing and a signed checksum manifest;
