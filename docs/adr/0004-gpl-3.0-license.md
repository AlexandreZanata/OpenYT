# ADR-0004: GPL-3.0 project license

- Status: accepted
- Date: 2026-11-09

## Context

The Android extraction path links `io.github.junkfood02.youtubedl-android`, which is
GPL-3.0. Distributing an Android application that links GPL-3.0 code requires the
combined work to be licensed under GPL-3.0. The desktop path invokes an external
yt-dlp executable (Unlicense) and could be licensed differently, but a split
license would complicate contributions and distribution.

## Decision

License the entire ClipBaú repository and distributed application under GPL-3.0.
Keep upstream notices in `THIRD_PARTY_NOTICES.md` and ship the license text with
packaged artifacts. Source remains publicly available.

## Consequences

- The Android app is license-compatible with the wrapper.
- Downstream forks must preserve GPL-3.0 obligations.
- No proprietary closed-source distribution of the combined app.
- Revisit only if the Android engine is replaced by a permissively licensed
  implementation, which is not planned.
