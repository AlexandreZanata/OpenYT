# Offline readiness capture provenance

Generated by `OfflineReadinessUiTest` from the real shared Compose
`OfflineReadinessCard` with deterministic fixture state. These images show the
component and its actual controls, not a complete native application window.

- `offline-desktop-en.png`: 960x420, English, light theme, normal text.
- `offline-phone-320-pt.png`: 320x640, Portuguese, light theme, 120% text.
- `offline-phone-large-dark-pt.png`: 360x640, Portuguese, dark theme, 160% text.

The capture host supplies the theme's opaque Material surface and content colors,
plus padding. The test checks every output pixel is opaque so GitHub's light or
dark page background cannot change the appearance of the image. It also verifies
readiness, pinning, cleanup confirmation/cancellation and missing-artwork recovery.

To regenerate all three images:

```bash
env -u WAYLAND_DISPLAY -u XDG_SESSION_TYPE xvfb-run -a ./gradlew :desktopApp:test --tests '*OfflineReadinessUiTest' --console=plain
```

Outputs are written to `desktopApp/build/ui-regressions/offline-*.png`; copy the
three reviewed files into this directory after the tests pass.
